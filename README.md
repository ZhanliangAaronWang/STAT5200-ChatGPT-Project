STAT 5200: ChatGPT experience and time savings
Aaron Wang

Question
Does previous ChatGPT use change the time savings from randomized encouragement
to use ChatGPT on a professional writing task?

Source
Noy, Shakked, and Whitney Zhang. 2023. Experimental Evidence on the Productivity
Effects of Generative Artificial Intelligence. Science 381(6654): 187-192.
https://doi.org/10.1126/science.adh2586
Data and original Stata code: https://osf.io/xd7qw/
Supplement: https://shakkednoy.com/ChatGPT_SM.pdf
Data downloaded October 29, 2026. The authors' identifiers are anonymized hashes.
The source_manifest.json records download URLs, sizes, and SHA-256 hashes.
Original data remain unchanged; their ownership remains with the source authors.

Run
Open a terminal in this folder and run:
    python3 scripts/download_data.py
    Rscript run.R
Only base R and its recommended standard packages are needed. The executed
environment was R 4.6.0 in WebR; outputs/sessionInfo.txt records its details.
The quality-check CSV is included. To rebuild it from the original workbooks:
    python3 scripts/prepare_quality.py
Python 3 standard-library modules are sufficient; no Excel package is needed.

Structure
data/raw/ is populated with four unchanged source files by the download script.
Raw source files are downloaded from OSF and verified against SHA-256 hashes.
data/derived/ contains the quality checks, original manual exclusions, and the
    participant-level analysis sample generated by scripts/clean.R.
scripts/ contains sample construction and descriptive statistics.
replication/ reproduces the unstandardized time coefficient underlying Figure 1A
    using Supplementary Equation S.1.
project/ adds the interaction between assignment and previous ChatGPT use.
outputs/ contains statistics, coefficient estimates, and the execution environment.

Sample construction
Keep completed surveys and exclude either explicit refusal of consent. Sort by
participant ID and start time and retain the first completed response. Apply the
six exclusions in the authors' 2 - clean.do (plagiarism, empty responses, prior
grading, and duplicate survey participation). These IDs are in excluded_ids.txt.
Recode quality-check value 3 to 1. Within each grading workbook take the minimum
and maximum check for each participant. If an ID occurs in both workbooks, use
grading.xlsx first, following the append-and-deduplicate order in the authors'
code. Exclude a participant when the maximum check exceeds 1 or the minimum is
below 1. Exclude participants whose task date follows their earliest grading date.
This recovers 453 participants. Restrict to linear and convex incentive arms for
the time analysis, leaving 356 (187 control and 169 treatment).

Variables
treatment: randomized encouragement to register for and use ChatGPT, 0/1.
prior_use: 1 if the pre-treatment usage response includes option 3 (ChatGPT),
    0 if it gives other options, missing if unanswered.
time1, time2: sum of self-reported brainstorming, drafting, editing, and other
    minutes on the first and second tasks. A missing component makes the sum
    missing; missing components are not silently replaced with zero.
change: time2 minus time1, measured in minutes.
occupation: participant occupation.
a_first: randomized ordering of the occupation-specific tasks.
incentive_arm: linear or convex payment scheme.

Results and interpretation
Descriptive statistics exclude missing values separately for each variable.
The replication has N = 346 and estimates -10.8424 minutes (HC1 SE 1.3821),
consistent with the paper's rounded 11-minute reduction.
The exploratory interaction model has N = 335. It estimates -12.2725 minutes
for previous nonusers and an interaction of 4.2684 (HC1 SE 2.9159). This is an
initial feasibility calculation, not a finished project result or evidence that
experience itself causes a difference. The interaction is not precise enough to
establish a difference using a conventional two-sided 5% normal test.
Randomization identifies assignment effects, subject to attrition and missingness.
These are not treatment-on-the-treated effects of actual ChatGPT use.

Next analyses
Compare missingness by assignment and prior experience. Check sensitivity using
recorded task duration. Report interaction confidence intervals and subgroup
assignment effects, and distinguish prior experience from actual task-2 usage.
Discuss compliance, selection into the observed sample, and external validity.
